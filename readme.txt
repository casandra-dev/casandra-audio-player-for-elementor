An all-in-one Elementor widget to easily create a highly customizable audio player, music player, WordPress radio, or podcast player.

== Description ==

Casandra Audio Player for Elementor is an all-in-one widget for building custom audio layouts with ease. With over 150 visual controllers, this plugin gives you freedom to build a WordPress radio station, music player, radio, or podcast player without touching a line of code. Every element is fully modular—reorder, toggle visibility, or fine-tune details to suit your needs. Plus, with deep styling and color options, you can match your player to any WordPress theme.

= Music Player and Radio DEMO & EXAMPLE =

Effortlessly design any player you can imagine. Check out these examples: [Demo](https://casandra.dev/audio-player-music-player-and-radio-for-elementor-demo/)

= Easy to Create Different Audio Players =

Unleash your creativity with a fully visual editor. Effortlessly toggle the sidebar or playlist, and customize colors, backgrounds, and properties directly within Elementor to bring your unique, desired UI vision to life. Every detail is under your control—you can even reposition elements, like moving the time slider to the top of the player.

= Advanced Music Player or Radio Station for Elementor =

Add your audio tracks in the WordPress admin, then drag and drop the music player or radio widget onto any page. From there, you can easily customize the design and functionality to perfectly match your vision.

= Music Player for Elementor =

Simply select your tracks and fine-tune the colors—your custom WordPress music player is ready to go. Enhance your player by setting cover images for the sidebar, top bar, or as a dynamic playlist background. Listeners can easily switch tracks, enable loop mode, and take full control of their audio experience.

= WordPress Radio for Elementor =

Need a WordPress radio station? It’s simple. Just disable manual playback controls, set your start time, and select a base time zone. Your radio will remain synchronized, playing tracks automatically according to your schedule. You have flexibility to change colors, toggle the playlist, or show/hide the sidebar—ensuring every functional detail matches your design perfectly.

= Podcast Player for Elementor =

Running a podcast? Give your audience an audio experience. Simply select your episodes, choose your style, and you’re ready to go. You have full control: hide the playlist and sidebar for a minimal look, or insert custom content like advertisements to monetize your show. The result is a beautiful podcast player that fits your brand.

= Minimal Audio Player for WordPress =

Create a minimal WordPress audio player with ease. Simply toggle off the sidebar, top bar, and playlist, or streamline the interface by minimizing controls and the duration bar. Every element is fully customizable, allowing you to style and color the player to blend seamlessly with your website’s theme.

== Installation ==

1. Install and activate *Casandra Audio Player for Elementor – Music Player, Radio & Podcast Player* [WordPress Documentation](https://codex.wordpress.org/Managing_Plugins#Installing_Plugins)
2. Add new tracks in WordPress dashboard -> Tracks
3. Create a new page or edit a page with Elementor.
4. Search for the "Audio Player" widget and drag it onto the page.
5. The player is ready to use. You can customize it with the Elementor widget editor controllers.
6. Save or publish the page.

== Frequently Asked Questions ==

= Where do I add my audio files? =

Go to Tracks in the WordPress dashboard and add Track posts.

= Does it require Elementor Pro? =

No, only Elementor (free).

= Can I use it as a radio station? =

Yes. Set a start time and base time zone in the widget.

== Source Code ==

The unminified JavaScript and SCSS source for the compiled files in /assets/js and /assets/css is included in the /assets-dev folder of this plugin.

Public repository: https://github.com/casandra-dev/casandra-audio-player-for-elementor

To rebuild the assets:
1. Run `npm install`
2. Run `npm run pack:p`
